# BriefPilot MVP scope

## Core promise

Turn a messy client inquiry into a qualified opportunity that is ready for a human decision.

## Must have

- Intake one realistic client inquiry.
- Extract structured project information.
- Maintain explicit opportunity state.
- Identify missing information.
- Generate only necessary clarification questions.
- Process the client reply.
- Escalate when a commercial or judgment-heavy decision is required.
- Show an inspectable activity trail.
- Use AWS Strands Agents in the final working build.
- Keep final commitments behind a human approval boundary.

## Should have

- Safe public website inspection.
- Local persistence.
- Live demo URL.
- AgentCore deployment if the MVP is stable.

## Explicitly out of scope

- Full CRM
- Invoicing
- Payments
- General calendar product
- Multi-tenant SaaS
- Team permissions
- Automatic pricing engine
- Automatic scope/deadline commitments
- Multiple specialized agents unless evidence shows one agent is insufficient
