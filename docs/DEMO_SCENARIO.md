# Demo scenario

## Opening

A freelancer or small studio receives a vague client inquiry:

> We have an existing WooCommerce shop and want to redesign the homepage and make discounts much more visible throughout the buying journey.

## Expected sequence

1. Inquiry received
2. Requirements extracted
3. Missing information identified
4. Clarification prepared
5. Client reply received
6. Opportunity updated
7. Human decision required

## Demo message

BriefPilot does not replace professional judgment. It removes repetitive intake work so the person sees a qualified opportunity only when a real decision is needed.

- 0:00–0:20 Problem and audience

- 1:20–1:50 Human judgment boundary
- 1:50–2:20 Architecture / Strands tools
- 2:20–2:40 Why it matters
